# 3DGrapsh_Finalproject
This is a repo for 3D graphs final project.

# 1 Project description
The purpose of this project is to demonstrate an understanding of all the OpenGL concepts
taught in class. This includes: loading OBJ objects, using the MVP matrices, applying
texture, applying lighting, creating a skybox, adding animation, using alpha blending and
using multiple textures.
# 2 Your job
You have to create a virtual scene using the Visual Studio code in eStudy. The scene should
include at least 10 instances of objects with at least 3 different shapes. It should have a FPS
camera in perspective view. Each object should have their own model matrix. There should
also be some animation in the scene. The scene should also utilize a skybox and multitextures (bump maps, specular maps, alpha maps, etc.)

## Requirements:
# 3D Model Loading
10 models and 3 VAOs (1.0)
6 models and 2 VAOs (0.75)

# Simple Textures
10 distinct textures (1.0)
6 distinct textures (0.75)

# Skybox
Skybox appears, follows camera, clear image, proper Culling and Depth Test (1.0)
Skybox appears, follows camera, clear image, improper Culling and Depth Test (0.75)

# Camera
First-person camera implemented correctly without bugs (1.0)
First-person camera working with some bugs (e.g., gimbal lock) (0.75)

# Lighting:
Uses Blinn-Phong with proper direction and normal matrix (1.0)
Uses Phong with proper direction and normal matrix (0.75)

# Multitexture
Has bump maps AND (specular maps OR night/day maps) (1.0)
Has only normal/bump maps (0.75)

# Alpha Blending
Alpha Blending for at least one semi-transparent texture WITH alpha map (1.0)
Alpha Blending for at least one semi-transparent texture WITHOUT alpha map (0.75)

# Data Structures and Software Quality
Well-structured, proper data types, well-commented, readable, variable names (1.0)
Well-structured, proper data types, some comments and indentation (0.75)

# Animation
Complicated motion path with relative motion for at least 5 models (1.0)
Complicated motion path with relative motion for at least 3 models (0.75)

# Advanced Feature (not necessary?)
Geometry shader programming, physics-based rendering, shadow mapping, particle animation, or other advanced OpenGL techniques (1.0)
Dynamic textures, dynamic scene creation, or procedural animation (0.75)
